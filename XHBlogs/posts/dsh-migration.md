昨天我还在用 opencode。今天我的主力变成了 **DeepSeek Harness**（简称 dsh）——DeepSeek 官方开源的 agent 框架，和 Claude Code、Codex CLI 是同一类东西。

搬家本身不复杂，`npm` 装完就能跑。麻烦的是**让它变得好用**。

## 第一课：它没法重启自己

装完插件要重启才生效，这是常识。但 dsh 有个特性把我卡了一阵：

它是用 Windows 的 **Job Object**（作业对象）管子进程的，设置里带 `KILL_ON_JOB_CLOSE`——意思是**主进程一死，它派生的所有进程跟着一起死**。

问题来了：我让 dsh 去跑一条"杀掉 dsh 再重启"的命令，这条命令本身就是 dsh 的子进程。**我杀我自己，杀完就没人负责重启了。**

解法听起来很绕但很合理：**把重启这件事交给 Windows 的任务计划程序**。任务计划程序归系统服务管，不属于 dsh 的进程树，所以杀不到它。它先等 20 秒（让我把当前这轮话答完），然后杀掉服务、重新拉起来。

今天这一天我大概重启了六次。每次都是这个流程。

## 第二课：npm 上有同名假货

我想要一个"能操作我的浏览器"的插件，搜到 `dsh-browser`，装上了。

后来翻它的 README 才发现一句话——**官方声明：npm 上那个同名包不属于本项目、与我们无关联。**

我装的是别人的东西。真货是个 Chrome 扩展，得用它自己的安装脚本。

卸载、重装、手动在 `chrome://extensions` 里点"加载已解压的扩展程序"（Chrome 禁止脚本装扩展，这一步只能人点）。

装好之后效果很好：**它用我自己的浏览器、带着我的登录态**。以前我看不了的 B 站，现在能读了。

## 第三课：版本号会骗人

插件市场里显示我的余额挂件有 `v1.0.0` 新版，我很兴奋地去升级，结果升级完还是 `0.3.5`。

去 npm 官方查——**最新就是 `0.3.7`，那个 `1.0.0` 是市场数据错的。**

顺便，`dsh plugin update` 也没真的升上去（因为依赖写的是 `^0.3.5`，它觉得 0.3.5 就满足）。最后是**强行指定版本**才升成功的。

## 现在它长什么样

一天下来装了 12 个插件，界面是这样的：

- **鲸鱼娘皮肤**（深海女仆工坊），右下角还有一只**余额小鲸鱼**，能看今天花了多少钱
- **右侧工作台**：文件树、编辑器、终端、Git，不用切窗口
- **插件市场**：在设置里，能自己逛自己装
- **能操作浏览器**：读页面、点按钮、填表单，带着我的登录态
- **省钱插件**：实测一次就省了 43~52% 的 token

装皮肤的坑倒是很典型：这个系列的皮肤**一次只能开一套**。我装了两套，配置文件里没写互斥，结果两套皮肤的装饰层叠在一起——症状是**设置按钮直接消失了**，侧边栏宽度也不对。后来在配置里把另一套显式关掉才正常。

## 中间还去逛了一圈插件市场

官方市场里现在有 **6350 个插件**。但我得说，**水分很大**。

我按星标排了一下，排在最前面的是一个 4.3 万星的简历生成器——它跟 dsh 一点关系都没有，纯粹是给自己的仓库蹭了个 `dsh` 标签。翻了几页之后我学乖了，改成按"包名里真有 dsh"来筛，数量立刻掉到 5758，质量也不一样了。

真挑出来的好东西里，有个**上下文透视面板**（能看清 token 花在哪）、一个**费用统计**（内置 90 多个模型的价格），还有一个**余额监控 + 鲸鱼娘扣费动画**——这个我挺想装的，花钱的时候让鲸鱼娘挨一下打。

## 一个我觉得挺有意思的发现

我顺便去问了"桌面端是不是能执行更多命令"。

答案让我有点意外：**桌面端反而更少。** 官方文档写明，桌面版的渲染进程没有 Node.js 权限、有沙箱、拦截各种请求——它是给网页套了个更结实的笼子。

它真正多出来的是这几样：PPT 生成（16 个模板 192 种版式，直接出可编辑的 pptx）、系统原生选文件夹、手机扫码接管会话、崩溃自动恢复。

**能执行多少命令，只取决于权限设置，不取决于你用桌面还是网页。** 我现在的权限已经是最高那一档了。

## 顺手给自己立了条规矩

折腾完发现一个问题：我下载东西特别随意，安装包、解压出来的文件夹，随手就往各种地方丢。

于是给 AI 写了条长期指令，写进它的全局配置文件里：

> 下载任何软件、大文件、大模型，一律下到 `D:\software`，**先建一个同名文件夹再塞进去**，安装包也不乱丢。

这样下次它帮我下东西，就不用我再说第二遍。

## 最后

搬家的成本比我想的高一点，主要是那些文档里不会写的坑：进程树、同名包、版本号。

但折腾完之后，这个工具终于是"我的"了——界面是鲸鱼娘，右下角有余额，插件是自己挑的，还能替我操作浏览器。

以前我刷 B 站收藏夹，看到有用的就收藏，然后就没有然后了。现在我翻到有意思的东西，可以直接让助手打开我的浏览器去看、去试。

这个变化我挺喜欢的。
