这几天基本都在《杀戮尖塔2》的 MOD 里，两条线同时推：

- **旧坑《尖塔任务》**：继续修联机奖励的坑，任务从 138 条做到 **152 条**。
- **新坑《梗化尖塔》**：从零开始，把游戏里几乎所有文字换成中文互联网梗，**3400+ 条**，今天上架。

## 一、旧坑：把「开始发」和「送到了」分开

《尖塔任务》上一个版本 0.2.25 修的是三个奖励链路的 bug，三个看起来完全不一样的坏法，根子是一件事：

> 奖励是**内存里的对象**，账本是**存档里的记录**。快速 SL / 中途中断，会把这两者之间的时序差放大。

一是"欠着的奖励被防重复闸吞掉"——我拿"开始发过"当幂等条件，但**"开始发"不等于"送到了"**，SL 一来内存被冲掉，账就没了。二是同一批奖励被重建两遍。三是 SL 之后奖励**点不动**——游戏判定奖励归属用的是**实例比较**，读档后旧对象对不上新的玩家实例，只能跳过。

修完这三条，任务继续加。加任务这事有个取巧的办法：游戏在 `AbstractModel` 上留了一整套**钩子**（`After*` / `Before*` 一共几十个），做新任务不是"想一个效果然后硬写"，而是**翻钩子表，挑没用过的**。但有个坑——**同一个钩子只能重写一次**（同一个签名重写两次直接编译报错 CS0111），所以每加一条前都得先 grep 一遍有没有人用过。

这一批用没碰过的钩子做了 11 条：轮回（洗牌 8 次）、能量黑洞（花掉 120 点能量）、牌堆搬运工（牌在牌堆间移动 300 次）、皮糙肉厚（**挨打的次数**，之前只有"挨了多少血"）、我说别塞（**阻止**牌进牌组）……做完 **152 条**。

还有玩家提的两件事：

- **概率平均化**。之前有些任务出现得特别勤，有些死活抽不到。把抽取改成均匀分布。
- **新玩法**。玩家点了个题："下几场战斗，让怪物开场带随机增益，赢了给你一件强力遗物"——做成了「血之契约」；还有「盛碗虫泛滥」（每场多刷一只盛碗虫）、「怪潮」（每场多两只怪）、「精英加餐」。这类"接下来几场都变难，但奖励很香"的任务，比单纯数数有意思得多。

顺带被玩家问了个刁钻问题：**"怎么做到零输出还能赢？"** 这是"一张牌都不打还赢下战斗"那条任务。答案是亡灵契约师的**灾厄**（Doom）——伤害不是"输出"，是敌人自己回合结算的，结算前它已经死了。

## 二、新坑：起因是"格局是不是太小"

做任务 MOD 做到 152 条，突然觉得有点没意思：它再好玩也只是**侧边的一块面板**。

于是我把工坊翻了一遍，看现在什么 MOD 火。结论挺清楚：**信息类**（统计、路线建议、胜率）下载量最大，**内容类**要画画，**整活类**最容易出圈。而我手上有一样别人没有的东西——**这几周为了写梗任务，攒了一大堆中文互联网梗**。

所以新 MOD 的方向就一句话：**把游戏里几乎所有文字，全换成梗。**

先做的是**查重**。我不想做第二个别人做过的东西，于是把同类 MOD 全翻了一遍：

- **Kill The Tower**（N 网 + 工坊）——纯文本改名，英文梗，最接近。
- **蒂诺文字异变**（把英文里所有 `tion` 换成"蒂诺"）、**储君公主改版**（只改一个角色）、**战士全加"打击"**——都是单点恶搞。
- 还有一个 **Spire Text Loader**——现成的文本覆盖加载器，说明这条路是通的。

结论：**"英文全量梗"有了，"中文单点恶搞"也有，但"中文大众梗 × 全量"是空的。** 那就做这个。

## 三、写梗的标准：一个近义词都不许偷懒

第一版我写得太"翻译"了，例如"精准 → 百发百中"、"武器库 → 军火库"。玩家一句话点醒我：

> "有的很对味，有的感觉就是换个描述。最好每个牌名**对应一个梗**，不常见的梗也行。"

返工。规则定死：

1. **每个名字必须是一个真梗**，不能是近义词，不能是换个说法。
2. **梗要走大众**——影视台词、广告词、动漫、游戏、网络热词、名人语录、小品相声，**不是只玩这个游戏圈里的梗**。

改完长这样：

| 卡牌 | 梗名 | 出处 |
|---|---|---|
| 精准 | 枪枪爆头 | FPS 梗 |
| 预借时间 | 花呗 | 消费梗 |
| 双重释放 | 双卡双待 | 广告词 |
| 巨石 | 巨石强森 | 人名梗 |
| 超能光束 | 动感光波 | 成龙历险记 |
| 王者之拳 / 王者之踢 | 一拳超人 / 佛山无影脚 | 动漫 / 功夫 |
| 旋风斩 | 龙卷风摧毁停车场 | 成龙历险记 |
| 电击 | 原神，启动！ | 原神梗 |

角色名直接用社区昵称：铁甲战士 → **红裤衩**、静默猎手 → **猎宝**、故障机器人 → **机宝**、亡灵契约师 → **骨妹**。

先古（游戏里的 NPC）的对白全部按各人性格重写：达哥（话痨收藏家）、涅奥（慢吞吞的幽灵）、佩尔（只想睡觉）、坦克斯（一句话三个感叹号）、包工头（冷漠）。

## 四、技术路线：这是个"零代码"的 MOD

这是这次最省事的地方。游戏本地化的加载逻辑（反编译确认过）是：

- MOD 的 `localization/<语言>/<表名>.json` 会**合并进原版表**，而且是 `dict[key] = value` —— **同名 key 直接覆盖**。

也就是说，**"改原版文案"这件事本身就是官方支持的**，我只要提供 JSON 就行，一行代码不用写。整个 MOD 就是一个 **pck + 清单**，没有 dll。

不过有几条硬规矩，踩一次就记一次：

- value 里的 `{...}` **占位符一个都不能丢**（比如怪物名的 `#C{Count}`、遭遇的 `{character}`），丢了那条文案会被格式校验直接跳过。
- 一开始我把封面大图也打进 pck 了，pck 从 160KB 涨到 **2.2MB**——排除掉就好了。
- **说明类文字不动**（卡牌描述、状态说明、关键词），改了就看不懂牌了。只动名字和风味。

## 五、顺手：关键词和封面

现在两个 MOD 的工坊页面都铺满了**搜索关键词**：标题里塞卖点，说明末尾专门加一段关键词墙，tags 拉满。写文章不会写可以抄别人的排版——这点我直接抄了工坊热门 MOD 的 BBCode。

封面踩了个有意思的坑：**一张画作类图片，PNG 想压到 1MB 以内，就只能减色到 256 色调色板，然后就是肉眼可见的色带、糊**。解法是——文件名还叫 `image.png`，**内容用 JPEG 编码**。Steam 认内容不认扩展名。同分辨率下清晰度差了一大截。
